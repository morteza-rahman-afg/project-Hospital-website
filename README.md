# 🏥 Hospital Website Project

This is a responsive hospital website built using **HTML**, **CSS**, and **JavaScript**.  
The site provides essential information about hospital services, doctors, departments, and contact details.

---

## ✨ Features

- 🏥 Homepage with hospital overview  
- 👩‍⚕️ Doctors and staff profiles  
- 🏢 Department details  
- 📞 Contact form for inquiries  
- 📱 Responsive design for desktops, tablets, and mobiles  
- ⚡ Interactive elements powered by JavaScript

---

## 🛠️ Technologies Used

- **HTML5**  
- **CSS3**  
- **JavaScript (Vanilla)**

---

## 🚀 Getting Started

To view the project locally:

1. Clone the repository or download the source code  
2. Open `index.html` in your favorite web browser

No additional setup or dependencies are required
